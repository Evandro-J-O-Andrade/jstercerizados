# JSEmpregos

## Plataforma SaaS para Gestão de Empresas de Terceirização

JSEmpregos é uma plataforma web moderna desenvolvida para empresas de prestação de serviços de:

- Segurança Patrimonial
- Controle de Acesso
- Portaria
- Zeladoria
- Limpeza
- Facilities

O projeto foi concebido como um SaaS escalável, permitindo a gestão de clientes, parceiros, fornecedores, candidatos e processos comerciais em um único ambiente.

---

## Objetivos

- Fortalecer a presença digital da empresa.
- Captar novos clientes.
- Centralizar solicitações comerciais.
- Receber currículos de candidatos.
- Gerenciar parceiros e fornecedores.
- Automatizar atendimentos via WhatsApp e E-mail.
- Preparar a empresa para atendimento com Inteligência Artificial.
