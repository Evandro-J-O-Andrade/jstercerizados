# 09 — n8n

## 09.1 Visão geral

n8n é o **orquestrador central** entre o site, Supabase e canais externos (WhatsApp, e-mail).

```text
Site
  ↓
n8n (webhook)
  ↓
Supabase + WhatsApp + E-mail + Slack
```

## 09.2 Workflows

### 1. Lead → WhatsApp + E-mail

```text
Trigger: Webhook POST /lead
  ↓
[Parse JSON body]
  → nome, empresa, email, phone, service, message
  ↓
[Format WhatsApp message]
  → "*Nova solicitação de serviço*\n\n*Serviço:* facilities\n..."
  ↓
[HTTP Request → Evolution API / Twilio]
  → envia WhatsApp para +5511968380592
  ↓
[SMTP Email]
  → comercial@jsterceirizados.com.br
  ↓
[Supabase Insert → leads]
  → status: 'new'
  ↓
[Response 200] → { success: true }
```

### 2. Chat escalation (IA → humano)

```text
Trigger: Webhook POST /chat-escalate
  ↓
[Supabase Insert → chat_rooms]
  → visitor_id, status: 'waiting'
  ↓
[Supabase Insert → chat_messages]
  → room_id, sender_type: 'system', content: 'Escalonado para atendente'
  ↓
[Slack Notification]
  → canal #atendimento → "Nova solicitação de chat"
  ↓
[Response 200] → { room_id: "..." }
```

### 3. Nova vaga publicada → WhatsApp broadcast

```text
Trigger: Supabase (vagas.status → 'active')
  ↓
[Format WhatsApp message]
  → "Nova vaga: {titulo} - {cidade}"
  ↓
[HTTP Request → Twilio]
  → lista de candidatos que deram match
  ↓
[Supabase Update → vagas]
  → notified_at
```

## 09.4 Integração no frontend

```ts
// Enviando lead do ServiceRequestForm
const response = await fetch(`${N8N_WEBHOOK_URL}/lead`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    nome,
    empresa,
    email,
    phone,
    cidade,
    service: serviceSlug,
    source,
    mensagem,
  }),
});

// Escalando chat da IA para humano
const response = await fetch(`${N8N_WEBHOOK_URL}/chat-escalate`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ visitor_id, subject }),
});
```
