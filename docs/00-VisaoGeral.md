# Visão Geral — JSEmpregos

## O que é

JSEmpregos é uma plataforma SaaS Enterprise projetada para empresas de terceirização de serviços, incluindo segurança patrimonial, portaria, controle de acesso, zeladoria, limpeza e facilities.

## Natureza do Projeto

**NÃO é um site institucional simples.** É uma plataforma SaaS completa que serve como porta de entrada para toda a operação comercial, recrutamento e atendimento da empresa.

## Funcionalidades Core

### Captação

- Solicitação de orçamentos
- Cadastro de parceiros B2B
- Cadastro de fornecedores
- Recebimento de currículos

### Gestão

- Painel administrativo (dashboard)
- Cadastros (clientes, parceiros, fornecedores, currículos)
- Pesquisa e filtros
- Exportação CSV
- Upload de PDFs e documentos

### Automação (Futuro)

- Integração com n8n
- Envio automático de e-mails
- Envio de WhatsApp via API
- Geração de leads
- CRM integrado

## Arquitetura

O projeto segue Feature-Based Architecture com Clean Architecture, garantindo baixo acoplamento e alta coesão. Toda a camada de serviços é desacoplada dos componentes, permitindo a troca de mocks por integrações reais sem alterar a interface.

## Público-Alvo

Empresas de terceirização que desejam:

- Fortalecer sua presença digital
- Captar novos clientes de forma profissional
- Centralizar solicitações comerciais
- Receber e gerenciar currículos
- Automatizar processos de atendimento
- Preparar-se para integração com CRM e IA
