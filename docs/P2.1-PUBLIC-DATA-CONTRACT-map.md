> `Route → Page → Hook → Repository → Supabase table/view → RLS

## Legend

| Tag       | Meaning                                    |
| --------- | ------------------------------------------ |
| REAL      | Backed by live Supabase table/view         |
| MOCK      | Hardcoded fallback / mock data             |
| STATIC    | No runtime data fetch; pure static content |
| PROTECTED | Requires authentication                    |

## 4. Supabase Views Summary

| View                       | Consumed By                                 | `security_invoker` | Purpose                                 |
| -------------------------- | ------------------------------------------- | ------------------ | --------------------------------------- |
| `public_jobs_v1`           | Home, Vagas, VagaDetalhe                    | `false`            | Published jobs for public display       |
| `public_companies_by_type` | Empresas, Clientes, Parceiros, Fornecedores | `false`            | Companies filtered by relationship_type |
| `public_services_v1`       | Servicos, ServicoDetalhe                    | `false`            | Published services for public display   |

All three views run with `security_invoker = false`, meaning they use the definer's rights and are safe for unauthenticated access.

## 5. Protected Public Routes

| Route                 | Protection                                                                                                   |
| --------------------- | ------------------------------------------------------------------------------------------------------------ |
| `/trabalhe-conosco`   | Reads `user.id` from `supabase.auth.getUser()` — requires session but creates a public candidate application |
| `/login`, `/entrar/*` | Auth flows — no data read from tables                                                                        |
| `/cadastro/*`         | Auth flows — no data read from tables                                                                        |
