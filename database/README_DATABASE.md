# JS Empregos SaaS — Database Documentation

## Overview

MySQL 8.0 database for the JS Empregos SaaS platform.

- **Database name:** `js_Empregos`
- **Charset:** `utf8mb4`
- **Collation:** `utf8mb4_unicode_ci`
- **Engine:** InnoDB
- **Migration target:** Supabase PostgreSQL compatible

## Key Tables

### empresa

Master/tenant table. All other data is scoped to an empresa via FK.

### usuarios

RBAC users. `perfil` defines the role. Permissions are many-to-many via `usuario_permissoes`.

### leads

All inbound contacts from the website forms, WhatsApp, Instagram, etc.

### clientes

Companies that hire services. Funnel: `LEAD → PROSPECT → NEGOCIACAO → CLIENTE_ATIVO`.

### contratos

Service contracts with expiration dates (used by automation alert).

### candidatos

Job applicants for positions (AUXILIAR_LIMPEZA, CONTROLADOR_ACESSO, etc.).

### tickets

Support tickets with protocol numbers, priority, and status.

### fila_automacao

Background job queue. Workers pick up `PENDENTE` jobs and execute webhooks/fluxos.

### conversas_ia

AI chatbot conversation logs (stored for analytics and training).

## Automation Events

| Código               | Descrição                                             |
| -------------------- | ----------------------------------------------------- |
| `LEAD_NOVO`          | Triggered when a new lead is created from the website |
| `LEAD_CONVERTIDO`    | Triggered when a lead is converted to a client        |
| `CONTRATO_VENCENDO`  | Triggered 30 days before contract expiration          |
| `TICKET_URGENTE`     | Triggered when a high-priority ticket is created      |
| `CANDIDATO_APROVADO` | Triggered when a candidate is approved                |
| `MENSAGEM_RECEITA`   | Triggered when a new WhatsApp message arrives         |
| `AUTOMACAO_DIARIA`   | Daily scheduled task                                  |

## Supabase Migration Notes

| MySQL                                 | Supabase (PostgreSQL)              |
| ------------------------------------- | ---------------------------------- |
| `AUTO_INCREMENT`                      | `GENERATED BY DEFAULT AS IDENTITY` |
| `ENUM(...)`                           | `VARCHAR` + `CHECK` constraint     |
| `TINYINT(1)`                          | `BOOLEAN`                          |
| `DATETIME`                            | `TIMESTAMP`                        |
| `JSON`                                | `JSONB` (better for querying)      |
| `ON UPDATE CASCADE`                   | Same syntax in PostgreSQL          |
| `utf8mb4`                             | `UTF8MB4` (native in Supabase)     |
| `TIMESTAMP DEFAULT CURRENT_TIMESTAMP` | `DEFAULT NOW()`                    |
